# svcmsp-site

Website for **Sovereign Vanguard Concierge MSP**, a Scalable Studio company. It is published by GitHub Pages at **https://svcmsp.scalablestudio.online**.

- `site.json`: everything the page says and how it looks. `build.js` turns it into `site/` (no packages).
- `.github/workflows/pages.yml`: builds and publishes on every push to `main`.
- **Concept preview:** the page carries a banner and noindex until Ken, Ann or Marty says go live (LIVE RULE).

Planning, blueprints and the punch list live in the private repo `ScaleableStudio/Sovereign-Vanguard-Concierge-MSP` (project #7).
